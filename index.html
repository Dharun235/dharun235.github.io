Robust Reinforcement Learning for Mobile Robot Navigation
  • Implemented TD3-based mobile-robot navigation and evaluated policy robustness against no-adversary, pure-pursuit, MPC/CEM, and learned reinforcement-learning adversaries.
  • Built an adaptive adversarial curriculum with configurable environments, multi-agent simulation, checkpointing, rollout-video generation, evaluation metrics, and Weights & Biases experiment tracking.
  • Compared navigation performance under adversarial disturbances using reproducible training and evaluation workflows documented in the project report.
↗ Report
Sensor Fusion and Non-Linear Filtering for 3D Object Tracking
  • Implemented LiDAR-based 3D vehicle detection in bird's-eye-view point clouds using pretrained deep-learning models.
  • Developed an extended Kalman filter with camera–LiDAR fusion, Mahalanobis-distance data association, and track management, achieving a mean tracking RMSE below 0.25 m across the evaluated sequence.
↗ GitHub
Development and Visual Tracking of Flapping-Wing Micro-Air Vehicles
  • Developed and tested voice-coil-driven flapping-wing micro-air vehicles, including control electronics, measurement devices, and interchangeable wing-hinge configurations.
  • Implemented camera-based wing tracking using colored-marker segmentation, histogram analysis, and centroid tracking under varying amplitudes, duty cycles, and hinge designs.
